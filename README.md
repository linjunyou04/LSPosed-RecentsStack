# LSPosed RecentsStack

A LSPosed/Xposed module for hooking SystemUI Recents.

## Features
- Hook SystemUI Recents with multiple strategies
- Save recent task info to `/sdcard/RecentsStack/tasks.json`
- DebugActivity for viewing and exporting logs
- GitHub Actions auto-build

## Usage
1. Install APK
2. Enable module in LSPosed
3. Reboot device or restart SystemUI
